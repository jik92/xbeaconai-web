# Seedance 人物参考遵循性对照测试设计

## 目标

通过一次可审计的真实 Seedance Mini 请求，区分人物不一致是业务参数转换错误，还是模型对人物参考图的遵循问题。

## 方案

- 直接使用项目现有 `AihubmixClient` 提交请求，避免业务审计将 Job 参数误当成 Provider 请求。
- 固定模型为 `doubao-seedance-2-0-mini-260615`，时长 15 秒、比例 9:16、分辨率 720p，并开启原生声音。
- 保持两张图片附件且顺序固定：`Image1` 为人像库 2，`Image2` 为原项目商品素材。
- 提示词仅保留人物身份一致、商品一致、简单展示动作、禁止其他人物和文字等必要约束，移除复杂微表情、镜头和营销修饰。
- 提交前输出脱敏后的最终请求摘要，明确记录 `extra_body.content` 的数量、类型、顺序和 URL 主机，不记录签名查询参数或密钥。

## 测试提示词

```text
15秒竖屏写实商品展示视频。@Image1 是唯一出镜人物，必须保持与参考图完全相同的脸型、五官、眼镜、胡须、发型、年龄、性别和身份，不得换脸，不得生成其他人物。@Image2 是商品帽子，必须保持外观、颜色、材质和黑色帽带一致。人物在户外自然光下先双手展示帽子，再戴上帽子面向镜头。全程人物身份一致，动作自然，禁止字幕、文字和水印。
```

## 验收

- Provider 请求包含两个按序排列的 `reference_image` 项。
- Provider 返回并下载可播放的约 15 秒视频。
- 抽取多个时间点画面，与人物参考图对比眼镜、胡须、脸型和整体身份。
- 将成片保存在本地结果目录，并提供可访问地址给用户查看。
