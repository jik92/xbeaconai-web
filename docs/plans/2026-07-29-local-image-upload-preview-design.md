# 本地图片上传预览设计

## 目标

让用户在提交前直接看见刚选择的商品图片，减少错误上传；共享上传入口也应具备相同能力。

## 方案

- 在共享 `FileUpload` 中为待上传的图片文件维护只读 data URL 预览映射。
- 文件列表变化时通过 `FileReader.readAsDataURL` 读取图片；移除文件或卸载组件时清理预览状态。
- 图片卡片使用真实 `<img>` 的完整比例预览；音频、视频和非媒体文件保持当前图标兜底。
- 已上传文件继续使用受鉴权媒体预览，原有上传、错误、重新选择和移除行为不变。

## 验收

- 商品创建选择 PNG、JPG、WEBP 或 GIF 后立即显示图片内容。
- 没有可用图片内容的文件仍显示通用图标。
- 不使用 Blob URL；切换或清空文件不会遗留已选图片预览。
