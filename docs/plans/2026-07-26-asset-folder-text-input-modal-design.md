# 素材文件夹通用输入 Modal 设计

## 目标

将素材库左侧文件夹区域的“新建文件夹”和“重命名”从浏览器原生 `window.prompt` 改为应用内统一的输入 Modal，并提供可供后续相同单字段输入场景复用的通用组件。

## 范围

- 新增受控的 `TextInputModal` 通用组件。
- 接入素材库的新建文件夹与重命名流程。
- 输入为空时在 Modal 内校验；接口失败时在 Modal 内展示错误并保留用户输入。
- 提交期间禁用关闭、取消和重复提交。
- 删除文件夹的确认流程本次不变。

## 组件契约

`TextInputModal` 接收打开状态、标题、字段标签、初始值、占位文本、确认按钮文案和异步提交回调。组件负责输入状态、首尾空格清理、必填校验、提交状态、异常展示，以及成功后的关闭行为。

Modal 使用现有 Radix Dialog、Input 和 Button 组件。头部只显示中文主标题，不增加副标题；表单使用明确标签；底部提供取消和确认按钮。按 Enter 提交，按 Escape 或关闭按钮取消（提交期间除外）。

## 素材库接入

文件夹区域维护当前编辑模式和目标文件夹：

- 新建时初始值为空，成功后刷新文件夹列表并选中新文件夹。
- 重命名时以当前名称作为初始值；名称未变化时直接关闭，否则提交接口并刷新列表。
- API 异常由通用 Modal 捕获并显示，不再调用原生 `alert`。

## 验证

- 通用组件单元测试覆盖必填校验、成功提交、异步错误保留。
- 素材库文件夹测试覆盖新建与重命名调用和 Modal 文案。
- 运行 `make ci`、`bun run typecheck`、`bun run build`。
