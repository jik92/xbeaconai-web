# 一键成片强制批量配音设计

## 目标

用户明确点击“批量生成配音”时，为所有存在口播文本且当前未在处理中的分镜重新生成配音。该操作会覆盖分镜原有的配音开关和已有音频状态。

## 行为

- 批量接口不再按 `audioEnabled`、已有音频或配置是否过期筛除分镜。
- 排除正在排队、生成或处理素材版本的分镜，避免与进行中的任务冲突。
- 排除没有可用口播文本的分镜。
- 入队时自动开启分镜配音；Worker 成功后写入新的音频产物和设置键。
- 单个任务失败时保留配音开启状态和真实错误，允许再次批量生成。

## 实现边界

- 保留普通视频批量生成中基于 `audioEnabled` 的现有选择逻辑。
- 只修改显式的 `/shots/batch-audio` 操作语义，不改变音色试听或单分镜开关接口。
- 继续为每个分镜创建独立 BullMQ Job，并沿用现有幂等键。

## 验证

- 单元测试覆盖配音开关关闭、已有音频、空口播和处理中分镜。
- API 测试覆盖强制批量入队与自动开启配音。
- Worker 测试覆盖成功和失败后的分镜状态。
- 运行相关单测、`make ci`、`bun run typecheck` 和 `bun run build`；按仓库约定不运行 E2E。
