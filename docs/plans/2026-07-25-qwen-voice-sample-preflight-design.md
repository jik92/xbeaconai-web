# Qwen 音色录音预检设计

## 目标

在 Qwen 音色人物任务创建前验证录音，并把可操作的失败原因直接显示在 Modal 中。

## 方案

- 新增 Qwen 录音预检服务，统一检查素材归属、音频类型、10MB 上限、可解码音频流以及 5–60 秒时长。
- 新增受 Bearer 鉴权保护的预检 API，输入当前用户拥有的素材 ID。
- 用户选中录音后立即预检；预检期间显示状态并禁用提交。
- 失败时在录音字段下显示实际结果，例如“当前录音 2.56 秒，至少需要 5 秒”。
- 成功时显示探测到的时长，并允许提交。
- 创建任务接口再次执行预检，防止绕过前端。
- Worker 保留最终校验，抵御素材在任务执行前发生变化。

## 数据流

Modal 选择素材后调用预检 API。服务从本地上传目录或 TOS 获取文件，在临时目录运行 ffprobe，返回时长、格式、声道和采样率；无论成功失败都清理临时文件。创建任务时通过同一服务复检后才入队。

## 边界

- 只接入 Qwen 独立音色人物流程。
- 不修改原有火山音色表单和任务行为。
- 错误响应使用现有结构化格式，不返回本地路径、TOS 地址或敏感配置。
- 不运行 E2E。
