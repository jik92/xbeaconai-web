# 一键成片共享视频生成参数设计

## 目标

让一键成片的批量生成和表格行内 AI 视频生成使用同一份页面级参数。默认模型为 Seedance 2.0 Mini，默认生成声音，并保证用户在设置弹窗中的修改立即作用于后续单条或批量提交。

## 界面与状态

- 页面维护一份共享的 AI 视频生成设置，包含模型、画面比例、清晰度和是否生成声音。
- 初始值为 Seedance 2.0 Mini、9:16、720p、生成声音。
- 打开批量生成弹窗时不再根据项目输入覆盖共享设置。
- 将当前固定的“不生成声音”提示改为可操作的生成声音开关；设置变更立即写入页面共享状态，不要求先提交批量任务。
- 批量生成按钮和每个分镜的“AI生成视频”“重新生成”“再生成”按钮都读取同一份共享设置。
- 保持现有紧凑弹窗、hairline 分隔和 shadcn 控件，不增加说明性副标题或页面专属 CSS。

## API 与任务参数

- 单条分镜生成接口增加与批量接口相同的请求体：`videoModel`、`ratio`、`resolution`、`generateAudio`。
- 批量接口的 `generateAudio` 从固定 `false` 改为布尔值。
- 两条接口都将完整设置传入现有 `enqueueVideoCreateOperation`，继续由同一任务参数路径传给 Worker 和 Seedance Provider。
- 服务端继续校验模型是否可用；单条接口补齐与批量接口一致的不可用模型响应。

## 生命周期

共享设置只存在于当前页面组件生命周期，不写入项目数据库或 localStorage。重新进入页面恢复默认值，避免设置跨项目残留，也不引入 Schema 或 migration 改动。

## 验证

- 更新 API 契约测试，覆盖单条和批量请求均接受布尔型 `generateAudio`。
- 更新前端行为测试，覆盖默认 Seedance 2.0 Mini、默认生成声音以及两个入口复用共享设置。
- 重新生成 OpenAPI 和 SDK，运行相关单测、类型检查、构建和完整 CI；按仓库规则不运行 E2E。
