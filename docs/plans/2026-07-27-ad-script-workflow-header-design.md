# 口播脚本统一流程 Header 设计

## 目标

口播脚本参考爆款二创的 Header 结构，在配置、生成中和结果页面始终显示同一个紧凑 Header。Header 同时承担模块识别、真实流程反馈和项目操作，替换配置页现有的大型三步导航，避免重复进度。

## 结构

- 左侧：口播脚本图标与模块名称。
- 中间：不可点击的语义化流程列表，依次为“选择场景、广告诉求、脚本风格、生成调优、脚本结果”。当前阶段使用 `aria-current="step"`，已完成阶段显示完成状态。
- 右侧：“生成记录”使用 `outline + sm`，“新建”使用 `ghost + sm`，与爆款二创保持一致。
- Header 在表单、生成进度和结果三个状态中复用；页面内容不再重复渲染标题栏或大型步骤导航。

## 阶段映射

- 表单 `step=0/1/2` 分别映射到前三个配置阶段。
- 生成进度页映射到“生成调优”。
- 结果页映射到“脚本结果”。
- Header 流程仅展示状态，不作为按钮；表单继续通过内容区的上一步、下一步完成导航。

## 项目操作

- “新建”清理当前项目态并回到第一步，保留现有草稿持久化规则。
- “生成记录”读取现有口播脚本项目列表，使用共享紧凑项目记录抽屉展示并恢复所选项目。
- 恢复运行中项目时进入生成进度页；恢复已完成项目时进入结果页；失败或取消项目进入可查看状态，不伪造成功结果。

## 验证

- 测试 Header 的五阶段语义、当前/完成态和按钮层级。
- 测试三个页面状态共用 Header，旧大型步骤导航和重复标题栏被移除。
- 测试历史项目恢复后的页面映射。
- 运行相关单测、类型检查和生产构建。
