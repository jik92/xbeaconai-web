# Seedance 2 商品图片引用保护设计

## 目标

爆款二创使用 Seedance 2 生成分镜视频时，必须向 Ark 提交至少一张图片参考。输入框旁边的参考图片区域是生成入参的唯一视觉事实来源：区域中可见的图片全部提交，区域为空时禁止提交。

## 数据流

1. 前端把当前商品图片、已选人像和手动添加图片合并为输入框旁边的可见参考图片区域。
2. 提交时直接把该区域中的全部图片写入 `references`、`referenceAssetIds` 和人像引用，不再依赖提示词中的 `@ImageN` 标签。
3. API 创建任务前检查 Seedance 2 视频请求至少包含一张普通图片或人像图片引用；缺失时返回 `SEEDANCE_IMAGE_REFERENCE_REQUIRED`，不创建任务、不扣创作点。
4. Worker 在调用 Ark 前再次检查准备完成的引用中至少有一张图片；缺失时抛出同一语义的不可重试错误，覆盖历史任务和内部调用。

## 行为边界

- 不自动选择商品首图，不自动修改提示词，也不通过 `@ImageN` 对可见图片做二次筛选。
- 可见图片为空或超过 9 张时，前端禁止提交。
- 当前商品图片和已选人像只要显示在参考图片区域中，就与手动添加的图片一样全部提交。
- 只约束 Seedance 2 视频生成，不改变其他模型或非视频任务。
- 原分镜的 `sourceAssetId` 继续只用于任务归属和谱系，不隐式作为生成参考视频。
- 保留现有最多 9 张图片、素材归属和提示词标签绑定校验。

## 验证

- 前端回归测试验证全部可见图片直接进入提交参数，且不再按 `@ImageN` 筛选。
- API 集成测试验证空图片引用被拒绝，带商品图片可正常创建任务。
- Worker 单元或集成测试验证绕过 API 的无图片 Seedance 2 任务不会提交 Ark。
- 运行相关测试、类型检查和生产构建。
