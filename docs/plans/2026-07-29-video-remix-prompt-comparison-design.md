# 视频脚本改写对比设计

## 目标

在爆款二创的脚本智能检查、脚本智能修改与智能更换口播完成后，先展示原文和改写后的双栏对比；用户确认后才应用改写。

## 交互

- 左栏显示“修改前”，右栏显示“修改后”，两栏滚动位置同步。
- 删除或被替换的行以红色标出，新增或被替换的行以绿色标出；未改动行保持普通样式。
- 改写结果不再自动触发 `onApply`。弹窗进入待确认状态，并保留任务的摘要和检查发现。
- 用户可编辑右栏内容、取消编辑恢复模型结果，或点击“应用修改”将当前右栏文本写回项目。
- “应用修改”后，当前版本成为新的基准文本；再次改写时以该文本作为对比原文。
- 应用后，提示词校对主页面右侧自动打开“对比版本”：保留左侧版本列表，右侧双栏重现本次修改，开关可切回单栏脚本。

## 实现边界

- 复用 `buildLineDiff` 和现有双栏 CSS，不引入新依赖。
- 将原有只针对“修正口播”的状态重命名为通用改写审核状态，以覆盖三个工具和两种口播模式。
- 保持现有任务提交、轮询、错误显示和 API 契约不变。

## 验证

- 单元测试断言弹窗包含通用审核、编辑、确认应用入口，且成功结果不在轮询回调中直接调用 `onApply`。
- 运行相关 Bun 测试、类型检查与生产构建。
