# 一键成片参考人物身份约束设计

## 背景

一键成片会把所选人像作为 `@Image1（人物）` 提交给 Seedance，但分镜模型生成的
`characterAppearance` 和人物动作仍可能包含与参考图冲突的性别、年龄、五官或发型描述。
当文字描述足够具体时，视频模型可能优先采用文字人物，导致参考人物未被还原。

## 设计

- 选择人物参考图后，最终视频 Prompt 的“人物形象”只声明参考图身份约束，不再拼接模型生成的
  `characterAppearance`。
- 身份约束明确要求保持参考人物的性别、年龄、脸型、五官、肤色、发型和身份特征，禁止替换主体。
- 分镜中的人物动作、构图、神态和背景继续使用原计划，但把常见的性别、年龄人物称谓改成中性的“人物”，
  避免“女生做动作”再次与男性参考图冲突。口播文案和音色设定不修改。
- 未选择人物参考图时保持现有 Prompt 行为，不影响纯商品生成。
- 参考图仍按当前已校验的附件顺序提交：人物为第一张 `Image1`，商品从 `Image2` 开始。

## 验证

- 单元测试覆盖人物参考存在时，冲突的外观描述不进入最终 Prompt，且动作语义保留并完成中性化。
- 单元测试覆盖未选择人物参考时，原人物外观描述仍会保留。
- 保留并运行已有的人物首图、商品后续图片顺序与引用校验测试。
