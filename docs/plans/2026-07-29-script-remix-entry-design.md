# 脚本二创入口设计

## 目标

在“创作工作流”侧栏增加“脚本二创”入口，提供独立访问路径，同时最大程度复用现有“爆款二创”的界面、任务和项目能力。

## 方案

- 新路径为 `/aigc/script-remix`，直接渲染现有 `RemixProject` 组件。
- `RemixProject` 接受可选的工作流标题；爆款二创维持默认标题，脚本二创传入“脚本二创”。
- 新建项目的默认名称沿用当前标题，便于在共享历史记录中区分来源。
- 因为后端任务、API 和持久化仍为 video-remix，本次不新增 ModuleId、OpenAPI 契约、数据库表或 Worker Job。
- 侧栏的脚本二创为手工入口，紧跟爆款二创，避免修改自动生成的 SDK 类型。

## 验证

- 单元测试断言路由存在、侧栏存在脚本二创入口，并断言该入口向 `RemixProject` 传入标题。
- 运行相关 Bun 测试、TypeScript 类型检查和生产构建。
