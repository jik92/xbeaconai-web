# 脚本二创：一键生成全部分镜并自动合片

## 目标

在脚本二创的“分镜校对”阶段提供一个主操作：批量提交所有已校对分镜的视频生成任务；每条分镜仍使用各自的提示词、引用素材和参数。所有分镜成功后，自动按当前时间线顺序创建合片任务。

## 范围

- 仅适用于 `workflowKind === "script"`。
- 保留单条生成入口，便于单镜调试和重做。
- 复用已有单分镜生成接口、Worker 和合片接口，不新增长视频生成协议。

## 交互与状态

1. 在分镜校对页的主操作区增加“一键生成全部并合片”。
2. 用户确认后，前端依次提交每个未成功的分镜任务，并为每个请求使用稳定的幂等键。
3. 页面显示批量进度（已提交、生成中、成功、失败）。单镜结果继续出现在原有分镜卡片中。
4. 所有分镜成功时，系统自动创建合片任务；若有任一分镜失败，不自动合片，并提供“重试失败项”。
5. 已成功的分镜不会在重试时再次提交或再次扣费。

## 数据与执行

- 前端根据每个分镜已有的 `ShotGenerationDraft` 生成提交快照，避免批量处理中读取已变化的编辑状态。
- 后端复用现有 `POST /api/video-remix/project/shots/generate` 的验证、计费、幂等和 Worker 队列；不改变 Seedance 单次时长限制。
- 批次状态仅作为前端派生状态，任务真实状态以已有子任务记录为准；页面刷新后通过子任务列表恢复。
- 自动合片复用 `POST /api/video-remix/project/compose`，且仅在每个源分镜均有成功生成物时执行。

## 异常处理

- 某一镜提交失败：继续尝试其他镜头，汇总失败原因。
- 某一镜生成失败：保留成功镜头，阻止自动合片，允许仅重试失败镜头。
- 合片提交失败：不影响已成功分镜，保留“重新合片”入口。

## 验证

- 单元测试：批次候选计算、已成功项跳过、失败项重试候选、自动合片条件。
- API 测试：批量触发沿用单镜幂等和计费语义。
- 运行：相关单测、Biome、类型检查、生产构建；不默认运行 E2E。
