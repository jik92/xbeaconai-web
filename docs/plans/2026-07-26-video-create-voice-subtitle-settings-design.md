# 一键成片配音与字幕设置设计

## 目标

在“一键成片”的分镜表格表头增加项目级“配音设置”和“字幕设置”入口。设置统一应用全部分镜，并作为后续生成默认值；真实配音使用火山语音，字幕预设必须真实影响 FFmpeg 烧录结果。

## 产品范围

- 配音仅支持当前已验证的四个火山语音预设：Vivi、刘飞、云舟、悬疑解说。
- 不增加截图中的其他音色，不提供“我的音色”。
- 配音支持慢、正常、快三档语速，以及广告营销、新闻播报、娱乐八卦三种表达风格。
- 字幕支持六个预设：思源白字、思源黄字、标题白字、标题黄字、快乐白字、快乐橙字。
- 保存配置不自动产生付费任务；用户明确点击“批量生成配音”后才提交任务。
- 已生成音频和已烧录字幕不会因保存设置被覆盖。配置变化后显示过期状态，由用户重新生成或合成。

## 交互设计

分镜表格保留配音与字幕全局开关，在各自表头旁增加紧凑的设置按钮。

配音设置使用标题单层的 Dialog：四张音色卡支持真实试听；下方选择语速和表达风格；底部提供“取消”“保存配置”“批量生成配音”。火山语音 Doctor 未通过时仍可保存，但试听和生成按钮禁用并显示现有结构化原因。

字幕设置使用标题单层的 Dialog：六张卡片展示与成片一致的示例文字；单选样式后保存。设置只控制后续字幕合成；已合成素材显示待重新合成状态。

## 数据模型

项目输入增加：

- `voiceSettings.presetVoiceId`
- `voiceSettings.speed`（`slow`、`normal`、`fast`）
- `voiceSettings.style`（`marketing`、`news`、`entertainment`）
- `subtitleStyleId`

分镜保存最近一次生成音频的配置指纹。素材版本保存字幕合成时使用的样式 ID。聚合响应比较项目配置与产物配置，公开 `audioStale` 和 `subtitleStyleStale`，不通过删除产物表示过期。

## API 与任务

- 新增项目媒体设置更新接口，校验 Bearer Token、资源所有权和执行中状态。
- 新增预设音色试听接口，真实调用火山语音并返回短音频；不回显密钥。
- 新增批量配音接口，只为开启配音且音频缺失或配置过期的分镜创建独立 BullMQ Job。
- 单分镜配音生成与替换使用同一火山语音边界，不再固定调用 AIHubMix `tts-1/alloy`。
- Job 值携带不可变设置快照，Worker 恢复与重试不读取后来修改的项目设置。
- 字幕预设集中定义，前端预览与 Worker 的 FFmpeg `force_style` 从同一预设派生。

## Provider 管理与门禁

恢复管理后台中的 `VOLC_SPEECH_API_KEY_ID` 和 `VOLC_SPEECH_API_KEY`，恢复火山语音 Doctor 检测和结果持久化。

火山语音不加入整个 `video-create` 模块的必需 Provider。新增配音操作级可用性，只禁用试听、批量生成和单分镜配音；分镜、字幕和无配音视频保持可用。

## 错误与一致性

- 保存设置时若有分镜任务执行中，返回结构化 409，不进行部分更新。
- 批量配音由服务端筛选并为每个符合条件的分镜创建独立 Job。
- 单个分镜失败不覆盖旧音频，不阻断其他分镜。
- Provider 未配置、Doctor 未通过、请求超时和上游拒绝分别保留可诊断错误码。
- 字幕重新合成产生新的素材版本，历史版本保持可恢复。

## 验证

- Doctor 恢复但不扩大整个模块门禁。
- 六种字幕预设映射到 FFmpeg 参数，前端预览使用同一配置。
