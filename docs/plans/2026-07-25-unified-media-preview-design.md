# 统一媒体预览设计

## 目标

将 Web 应用中的业务图片、音频和视频展示统一为独立组件，并提供一致的全屏预览交互。

## 范围

- 覆盖素材库、上传组件、任务结果、视频创作、视频二创和视频混剪中的业务媒体。
- 不覆盖 Logo、头像等装饰性图片。
- 不改变视频编辑器画布内承担剪辑或合成功能的媒体元素。
- 支持鉴权 API 地址与浏览器本地 Blob URL。

## 组件设计

`MediaPreview` 是业务入口，根据 MIME 类型分派到 `ImagePreview`、`VideoPreview` 或 `AudioPreview`。
三个独立组件负责各自原生元素、元数据回调和可访问性语义。鉴权地址仍由统一加载层转换为短期 Blob
URL，并在地址改变或组件卸载时释放。

视频使用 `react-player@3.4.0` 作为唯一播放内核。鼠标进入缩略预览时从当前进度播放，移出时暂停并
保留进度；右上角持续显示当前秒数和总秒数。双击视频打开全屏预览，并从同一进度继续自动播放；关闭
全屏后进度同步回缩略预览。素材库不再叠加独立的播放按钮或浏览器原生 controls。

音频使用独立 `InteractiveAudioPreview` 卡片，但复用相同的播放状态、时间格式和全屏进度同步模型。
由于鉴权音频会转换为没有文件扩展名的 Blob URL，而 ReactPlayer 依赖扩展名区分 HTML 音频和视频，
音频底层保留原生 `HTMLAudioElement`，不显示原生 controls。卡片移入播放、移出暂停，右上角显示
当前秒数和总秒数，双击进入全屏音频播放器。

`MediaLightbox` 提供共享全屏 Dialog。视频双击打开，图片点击打开，音频通过全屏按钮打开。全屏视频
提供 ReactPlayer 的播放、进度和音量控制；图片按原比例居中适配。关闭按钮、遮罩空白区域和 Escape
均可关闭；关闭会暂停媒体。

现有 `AuthenticatedMedia` 保留为兼容导出并委托给新组件，避免大范围调用点同时发生无意义重命名；
本地上传预览改为直接复用相同的媒体组件。

## 视觉与交互

全屏层使用深色半透明遮罩，使各种比例的媒体都保持清晰。关闭按钮使用已有 Button 组件和圆形图标
按钮样式，不增加标题、副标题或说明文案。媒体主体使用 `object-contain`，全屏音频使用紧凑的白色
控制面板。缩略图保持各页面原有尺寸和布局。

## 错误与边界

- 加载失败继续显示调用方传入的错误文案。
- 浏览器阻止有声自动播放时保持暂停状态，用户可使用全屏控制条手动开始。
- 非图片、音频或视频 MIME 类型不进入统一媒体预览。
- 交互按钮、链接、输入框和原生媒体控件的点击不触发全屏。

## 测试

单元测试验证媒体类型分派、全屏开关、自动播放属性、关闭语义、Blob URL 生命周期和主要业务入口复用。
交付验证运行相关 Bun 单测、`make ci`、`bun run typecheck` 和 `bun run build`；按仓库要求不运行 E2E。
