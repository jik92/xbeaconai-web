# 新建任务可选保存素材库设计

## 目标

AI 工具箱的新建任务首次默认“不保存素材库”。用户主动选择文件夹后，本次任务才把产物写入素材库，并按模块记住该文件夹；用户切回“不保存素材库”后，清除该模块默认文件夹。

## 状态模型

- 模块没有 `module_output_folder_defaults` 记录：默认不保存素材库。
- 模块存在默认文件夹记录：默认保存到该文件夹。
- `outputFolderId` 为空字符串：本次不保存素材库。
- `outputFolderId` 是当前账号拥有的文件夹 ID：本次保存素材库。
- 选择“不保存素材库”通过 API 删除模块默认记录，不使用虚拟文件夹。

## 交互

公共 `SaveLocationPicker` 的第一项固定为“不保存素材库”，且可以选择。首次打开模块时保持该项；存在模块默认文件夹时自动选中该文件夹。选择文件夹或新建文件夹会更新模块默认，选择“不保存素材库”会清除模块默认。

保存位置不再是任务提交的必填项。没有选择文件夹不显示校验错误，也不禁用提交按钮。

## 数据与执行链路

模块默认文件夹 GET 接口返回可空 `folder`，PUT 接受可空 `folderId`。Store 在空值时删除默认记录。

任务 API 只在 `outputFolderId` 非空时验证所有权。Worker 在有文件夹时创建素材库资产；没有文件夹时将结果写入 `.data/results/` 并登记为任务 Artifact，保持任务结果可预览和下载，但不出现在素材库。

## 验证

- Store 测试覆盖首次无默认、设置文件夹、清除默认和模块隔离。
- API 测试覆盖可空 GET/PUT 与无文件夹任务提交。
- 组件测试覆盖默认“不保存”、选择文件夹、切回“不保存”和新建文件夹。
- Worker 测试覆盖无文件夹时不创建素材资产、有文件夹时维持原有行为。
- 运行相关单测、类型检查和生产构建。
