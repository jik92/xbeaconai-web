# 一键成片脚本与分镜段数解耦设计

## 目标

“分镜段数”只控制最终生成的分镜数量，不再控制脚本的语义模块数量。脚本总字数和总时长由视频时长与配音语速推算。

## 脚本生成

- 脚本按语义模块拆分显示，模块数量由模型根据内容动态决定。
- 至少包含“开场痛点”“产品介绍”“收尾引导”三个模块。
- 模型可以按内容增加使用场景、卖点拆解、信任背书、优惠信息等模块。
- 所有模块合计的目标字数由视频时长乘以语速对应的每秒字数计算：慢速 3 字/秒、中速 4 字/秒、快速 5 字/秒。
- 所有模块的时长合计应接近用户选择的视频时长。
- 脚本生成提示词不读取分镜段数；页面继续支持逐模块编辑和逐模块“换一版”。

## 分镜生成

- 分镜阶段读取完整脚本，并严格生成用户设置的分镜数量。
- 模型在分镜阶段把完整口播重新切分到各分镜，每个分镜返回画面提示词、口播文本和时长。
- 分镜保存独立的口播文本快照。配音、字幕、单镜视频生成和最终合成均读取分镜口播，不依赖脚本模块与分镜的一一对应关系。
- 脚本语义模块数量可以少于、等于或多于分镜数量。

## 数据与兼容

- 在分镜记录中新增口播文本字段，通过新的 Drizzle migration 演进数据库，不重写历史 migration。
- 新生成的分镜必须写入口播文本。读取旧数据时，如果该字段为空，暂时回退到原有关联脚本模块文本，避免已有项目失效。
- 脚本一旦生成分镜仍保持锁定，因此分镜口播快照不会与可编辑脚本产生无提示的漂移。

## 校验与交互

- 删除生成脚本时针对分镜数量的校验。
- 用户切换视频时长时不再自动修改分镜段数。
- 单镜仍受视频模型最长 15 秒限制。如果当前分镜数无法覆盖目标视频时长，只在生成分镜时返回明确错误，不阻止脚本生成和编辑。
- 分镜生成结果必须与请求的分镜数量一致，且每段口播非空、时长合法。

## 验证

- 单元测试覆盖目标字数计算、动态脚本模块提示词、分镜数量约束、独立口播持久化和旧数据回退。
- API 测试覆盖脚本生成不再受分镜数量限制，以及分镜生成阶段的最小分镜数量错误。
- 重新生成 migration，并运行数据库检查、相关单测、类型检查和生产构建。
- API Schema 没有对外字段变化时不重新生成 SDK；若分镜响应暴露口播字段，则同步导出 OpenAPI 并重新生成 SDK。
