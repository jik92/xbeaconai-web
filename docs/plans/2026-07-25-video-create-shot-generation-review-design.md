# 一键成片单分镜视频生成核实设计

## 目标

将一键成片表格中的“AI生成视频”“重新生成”“再生成”改为先核实、后提交的单分镜生成流程。用户在 Modal 中看到并可调整最终提示词、视频参数和实际绑定附件，提交内容与 Worker 最终收到的内容保持一致。

## 交互

- 点击行内生成按钮先请求服务端生成草稿，再打开大尺寸“AI生成视频素材”Modal，不立即创建任务。
- Modal 顶部展示当前分镜序号、时长和口播文案；中间提供可编辑的最终提示词和实际附件预览。
- 底部集中展示模型、参考模式、比例、清晰度、时长、Seedance 原生声音和当前真实或 Mock 执行模式。
- 支持通过已有 `AttachmentPicker` 增删素材；引用素材显示名称、MIME 类型、用途和鉴权预览。
- 提交前校验提示词、时长、模型能力、素材类型、素材归属、每类数量、总数、大小以及提示词内的 `@附件名`。
- Mock 功能和 `MOCK_GENERATE_VIDEO_API` 保持不变，Modal 只如实显示当前执行模式。

## 提示词构建

- 服务端根据当前分镜画面提示词、对应脚本口播、分镜序号、时长和绑定附件确定性构建最终提示词。
- 提示词包含画面生成要求、口播内容、附件引用、商品与人物一致性、时长、声音要求和禁止生成画面文字要求。
- Modal 返回的提示词可编辑；提交时服务端保存并透传用户最终确认版本，不再回退到旧的 `shot.prompt`。

## API 与数据流

- 新增单分镜生成草稿接口，返回分镜上下文、构建后的提示词、默认参数、实际附件、附件限制和执行模式。
- 扩展单分镜生成请求体，包含 `prompt`、`duration`、`referenceMode`、`referenceAssetIds`、可选 `portraitId`、模型、比例、清晰度和 `generateAudio`。
- 服务端不信任前端附件元数据，只接收 ID，重新执行用户归属、MIME 和限制校验后写入最小 Job values。
- Worker 继续通过现有 Seedance 边界上传参考素材并提交 AIHubMix；真实与 Mock 共用相同任务参数。
- 批量生成接口与现有交互保持不变。

## 声音说明

- `generateAudio` 继续控制 Seedance 原生音轨。
- 现有分镜 TTS 和字幕流程暂不改变；Modal 明确显示当前后续配音为 `tts-1 / alloy`，且分镜配音开启时最终合成会替换视频原生音轨。

## 视觉与响应式

- 参考用户截图的白色大尺寸弹窗、圆角编辑区、附件缩略图、底部参数控制和右下角提交按钮。
- 使用现有 Dialog、Button、Switch、NativeSelect、AttachmentPicker、AuthenticatedMedia 与 Tailwind Token，不新增页面专属 CSS。
- 桌面端适配 1440×900；1024×768 下 Modal 内部独立滚动，底部提交区保持可见。

## 验证

- 单测覆盖提示词构建、默认附件解析、附件归属与类型限制、请求参数透传、真实和 Mock 执行模式展示。
- API 契约变更后重新生成 OpenAPI 与 SDK。
- 运行相关单测、`make ci`、`bun run typecheck` 和 `bun run build`；按仓库要求不运行 E2E。
