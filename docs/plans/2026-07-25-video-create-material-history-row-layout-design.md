# 一键成片生成历史单行布局设计

## 目标

将分镜“生成历史”从双列视频卡片改成一条视频一行的横向列表，让用户能同时比较视频、生成参数、执行时间，并通过明确的操作按钮选择对应版本。

## 组件复用

- 保留现有 `VideoCreateMaterialHistoryDialog`，不新增平行业务弹窗。
- 视频继续使用 `AuthenticatedMedia`，保持鉴权播放和错误处理一致。
- 操作继续使用共享 `Button`，加载状态使用现有 Lucide 图标。
- 使用现有 Tailwind Token、表面色、分隔线和排版，不新增业务 CSS 或新的基础 UI 组件。
- 不使用标准 `DataTable`：其 56px 行高不适合可播放的视频预览，但列表行仍遵循共享表格的紧凑分隔语义。

## 布局

每个素材版本独占一行：

1. 左侧为固定宽度的 16:9 视频预览。
2. 中部第一组展示来源、状态以及生成参数：模型、请求时长、比例、分辨率、原声和字幕合成状态。
3. 中部第二组展示提交时间、完成时间和总耗时。
4. 右侧为“选择此版本”按钮；当前版本显示“当前使用”并禁用。

桌面端保持一行。窄屏下行内容允许换行，视频、参数、时间和操作依次纵向排列，按钮仍使用共享尺寸。

## 数据契约

素材版本通过 `jobId` 关联任务。历史接口在现有版本数据上增加可选的 `generation` 和 `execution`：

- `generation`：模型、时长、比例、分辨率、是否生成原声。
- `execution`：提交时间、完成时间、耗时秒数。

AI 生成记录从任务字段读取。配音替换、字幕合成可显示对应任务时间；素材库替换和本地上传没有任务参数时显示 `—`。接口继续校验项目、分镜和用户所有权，不接受前端提交的用户标识。

## 状态与操作

- 成功且文件可用：允许选择。
- 当前版本：显示“当前使用”，不可重复选择。
- 处理中：显示加载状态和“生成中”。
- 失败：展示结构化错误信息并禁用选择。
- 文件不可用：显示“文件不可用”并禁用选择。

选择成功后沿用现有回调刷新项目与历史列表。

- API 契约测试覆盖新增参数和执行时间字段。
- UI 单元测试覆盖单列行布局、复用组件、参数与时间展示、选择按钮文案。
- 重新生成 OpenAPI 与前端 SDK。

- 按仓库要求不运行 E2E，由用户完成页面手动验收。
