# AI 创作侧栏分组设计

## 目标

- 应用侧栏首次访问时默认使用图标折叠模式，并继续保存用户后续的展开或折叠选择。
- 新增一级菜单分组“AI创作”，其中仅包含“素材生成”和“素材理解”。
- 原“AI 创作”菜单项仅在侧栏中改名为“素材生成”，页面标题、路由和模块标识保持不变。
- 其余原“AI 工具箱”菜单项继续保留在“AI 工具箱”分组。

## 实现

- 在侧栏展示层新增“AI创作”分组，并按模块 ID 将 `ai-generate` 与 `media-understand` 从“AI 工具箱”筛出。
- 为 `ai-generate` 覆盖侧栏标签，不修改模块的业务配置，避免影响页面文案、搜索之外的业务逻辑和 API。
- 当 `sidebar-collapsed` 尚未写入本地存储时使用折叠状态；键存在时沿用已保存的用户选择。
- 复用现有菜单偏好归一化逻辑，使新增分组自动获得默认顺序，同时保留各菜单项已有的显隐偏好。

## 验证

- 添加侧栏菜单构造与默认折叠状态的单元测试。
- 运行相关单元测试、类型检查和生产构建；不运行 E2E。
