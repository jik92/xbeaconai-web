# 爆款二创按钮颜色一致性设计

## 问题

爆款二创根容器通过高优先级选择器将大多数按钮的边框清空、背景设为透明。共享 shadcn `Button` 的 `default` 变体仍保留 `text-on-primary`，因此这些按钮出现在浅色页面或弹窗中时会形成白底白字。该规则还会覆盖后续新增的共享按钮，使问题持续复发。

## 设计

- 删除 `.remix-project` 下针对所有按钮的背景和边框重置。
- 爆款二创所有按钮继续使用共享 `Button`，按语义显式选择变体：主操作使用 `default`，次操作使用 `outline`，低强调操作使用 `ghost`。
- 选中态同时指定背景和文字色，浅色背景只能使用深色文字；`text-on-primary` 只能与深色或语义色背景成对出现。
- 业务 CSS 只保留布局、尺寸和确有必要的特殊结构，不再通过页面级规则接管共享按钮颜色。
- 不改变业务流程、按钮文案、弹窗布局和既有紧凑尺寸。

## 验证

- 增加静态回归测试，禁止重新引入页面级按钮背景重置。
- 审计爆款二创按钮的 `default`、`outline`、`ghost` 和选中态组合。
- 运行按钮使用测试、爆款二创配置测试、类型检查和生产构建。
