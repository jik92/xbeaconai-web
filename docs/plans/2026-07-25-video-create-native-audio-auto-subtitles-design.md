# 一键成片原声与自动字幕设计

## 目标

让分镜生成参数与分镜编辑状态保持一致：生成视频选择“有声”时保留视频原声并自动关闭该分镜配音；字幕开关开启时，单个分镜生成完成后直接产出已烧录字幕的视频。

## 方案

- 单个和批量分镜生成都把 `generateAudio` 持久化为分镜配音状态：有声视频设置 `audioEnabled=false`，无声视频设置 `audioEnabled=true`。
- Worker 仍生成 TTS 音频和字幕时间轴，供无声视频配音、字幕计时和后续编辑使用；有声视频不会在最终合并时被 TTS 覆盖。
- 当 `subtitleEnabled=true` 时，Worker 在基础视频生成后立即使用当前字幕时间轴烧录字幕，将处理后的文件保存为本次素材版本的最终内容。
- 素材版本增加 `subtitlesComposed` 状态。AI 自动烧录和手动字幕合成设为 `true`；上传、素材库替换和新的基础生成按实际结果设置；配音替换继承输入版本状态。
- 最终合并只对 `subtitleEnabled=true` 且当前素材版本尚未合成字幕的分镜补做字幕，防止重复字幕。

## 一致性与失败

- 音频开关更新在任务入队时写入数据库，因此刷新页面、关闭页面或 Worker 重启都不会丢失。
- 自动字幕属于分镜生成任务的一部分；字幕烧录失败时任务整体失败并保留可重试状态，不把无字幕视频标记为成功。
- 历史素材版本保留各自的字幕合成状态，切换历史版本后最终合并按当前版本状态判断。

## 验证

- Store/API 单测覆盖单个与批量任务的有声/无声配音状态。
- Worker 单测覆盖字幕开启自动烧录、字幕关闭跳过，以及最终合并避免重复烧录。
- 运行相关单测、数据库迁移检查、OpenAPI/SDK 生成、类型检查、构建和 `make ci`；按仓库规则不运行 E2E。
