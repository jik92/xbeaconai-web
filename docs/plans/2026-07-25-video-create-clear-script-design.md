# 一键成片清除脚本设计

## 目标

在脚本结果页的【复制脚本】旁增加【清除脚本】，让用户清空当前脚本及依赖分镜后重新调整参数并生成脚本。

## 交互

- 【清除脚本】使用次要危险操作样式，位于【复制脚本】旁。
- 点击后显示确认 Dialog，说明脚本和当前分镜会被清除，但已经生成的视频、音频及素材库文件会保留。
- 确认成功后清空页面编辑草稿，项目回到脚本空状态，并继续停留在脚本页；用户可直接点击【生成脚本】。
- 请求失败时沿用页面现有错误提示，不隐藏服务端业务错误。

## API 与持久化

新增受 Bearer Token 保护的项目脚本清除接口。服务端验证项目归属，并通过 Store 事务按顺序删除：

1. 当前项目的分镜记录；
2. 脚本段落的所有版本；
3. 脚本段落。

事务同时将项目恢复为 `draft`，清除当前 Job、最终成片关联和项目错误。商品、人像、音色、生成参数和项目本身保持不变。分镜引用的生成视频、音频及素材库对象不执行物理删除，只解除当前项目关联。

## 并发安全

项目处于分析、脚本生成、分镜生成或合并阶段时禁止清除。任一分镜处于排队或生成状态时同样返回 409，避免 Worker 在清除后回写已删除记录。所有权不匹配返回 404。

## 测试

- Store 测试覆盖脚本版本和分镜同时清除、项目恢复草稿、输入参数保留。
- API 契约覆盖清除接口及 200、404、409 响应。
- 前端行为测试覆盖按钮位置、确认文案、成功后清空本地草稿。
- 运行 OpenAPI/SDK 生成、完整单元测试、类型检查和生产构建；不运行 E2E。
