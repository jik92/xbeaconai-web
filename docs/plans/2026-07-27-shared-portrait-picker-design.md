# 爆款二创与一键成片共享人像选择器设计

## 问题

一键成片使用 `portrait-library/portrait-picker-dialog.tsx`，爆款二创则在 `remix-project.tsx` 内维护另一套人像弹窗。两套实现的数据源相同，但筛选、卡片、选中反馈、加载更多和底部确认交互不同，后续修改容易继续漂移。

## 方案

扩展现有 `PortraitPickerDialog`，让它同时支持单选和有限多选：

- 共享组件接收 `selectedKeys`、`maxSelect` 和一次性 `onConfirm`。
- 一键成片传入一个已选 key 和 `maxSelect={1}`，保持单选语义。
- 爆款二创传入当前已选 key 列表和 `maxSelect={3}`，保留最多三个人像。
- 组件内部统一管理临时选择、通用/自建来源、性别、搜索、加载更多、上限提示、卡片选中态和底部确认。
- 多选达到上限后，仍允许取消已选项；点击其他未选项不会替换或超出上限。
- 弹窗取消不写回业务状态，确认后由业务页面转换或保存自己的数据结构。
- 删除爆款二创内部的 `PortraitPickerModal` 及其专用 CSS。

## 备选方案

- 仅复制共享弹窗样式到爆款二创：视觉暂时一致，但仍保留两套行为实现，不采用。
- 两个模块都改为单选：实现简单但会移除爆款二创已有能力，不采用。

## 验证

- 为共享组件补充单选、多选、选择上限、取消不提交和确认提交测试。
- 更新静态测试，确保爆款二创不再定义内部人像弹窗并复用共享组件。
- 运行相关单元测试、Biome、TypeScript 类型检查、生产构建和差异检查。
