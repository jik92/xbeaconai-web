# 爆款二创 Header 语义修复设计

## 目标

- 左侧创作阶段呈现为流程进度条，不使用按钮外观或按钮语义。
- 右侧“生成记录”和“新建”保留为真实操作按钮，统一使用白底黑字的 compact shadcn `Button`。
- 保持现有 Header 高度、三栏结构和阶段状态表达，不扩展业务功能。

## 结构

流程区域使用带 `aria-label="创作进度"` 的 `<ol>`，每个阶段使用 `<li>`。当前阶段设置 `aria-current="step"`，已完成阶段继续显示勾选图标，阶段之间保留箭头。流程节点不绑定点击事件，不伪装成可交互控件。

`WorkflowHeader` 删除 `onStage` 参数；页面仍由现有工作流状态驱动当前阶段，Header 不再负责回退或切换阶段。

## 视觉

- 流程节点保持现有 24px 圆形序号、12/14px 语义字号和已完成/当前状态颜色。
- 移除流程节点的按钮高度、hover、焦点和点击指针表现。
- 右侧两个操作使用 `variant="outline"`、`size="sm"`，由共享组件提供 32px 高度、边框、白色表面和黑色文字。
- Header 业务 CSS只负责区域布局和进度条状态，不重新定义按钮文字颜色。

## 验证

- 源码测试确认流程使用 `<ol>/<li>` 且不在 `.remix-steps` 中渲染 `Button`。
- 源码测试确认右侧操作使用共享 `Button` 的 `outline` 与 `sm` 规格。
- 运行相关单元测试、类型检查和生产构建；不运行 E2E。
