# 音色库列表行布局设计

## 目标

修复音色库在长文件名或描述下发生文字重叠的问题，让每条音色始终保持清晰、可试听、可选择。

## 方案

- 保持现有横向 `voice-row` 列表，不改为卡片或网格。
- 左侧保留固定 32px 音色图标；中间使用名称、描述或原文件名、文件大小与创建日期三行内容区。
- 三行文字均限定单行并截断，内容区使用 `min-w-0`，避免长文本挤压右侧操作。
- 右侧试听按钮或播放器使用不可收缩容器；试听展开时仍限制在行内可用宽度。
- 保持列表区域自身滚动；不调整上传、删除、选择音色与试听的数据流。

## 验收

- 长音色名称、描述及原文件名不再覆盖日期或大小。
- 试听操作始终可见、可点击。
- 窄内容区域下文字省略而不折叠重叠。
- 现有音色库相关单元测试、类型检查与构建通过。
