# AI 创作参考素材入口设计

## 目标

在 AI 创作页面提供一个统一的“添加参考素材”入口，让用户能从素材库选取或从本地上传图片、视频；选中的素材以可移除卡片显示，并按当前模型的引用能力限制可见素材类型。

## 现状

- `AttachmentPicker` 已同时支持素材库选择和本地上传，并可按 MIME `accept` 参数筛选。
- AI 创作的生成请求已通过 `referenceAssetIds` 提交引用素材，服务端会校验所选模型允许的图片/视频类型及引用数量。
- 当前页面入口文案为“@ 引用素材”，没有让用户在界面上清楚区分图片、视频或当前模型支持范围。

## 交互方案

1. 将入口调整为“添加参考素材”，保留一个按钮。
2. 打开选择器时根据当前模型的 `acceptedReferenceKinds` 生成 `accept` 值；未被模型支持的图片或视频不会在素材库中出现，也不会被本地上传选择器接受。
3. 选择器在素材库区域提供“全部 / 图片 / 视频”类型筛选；本地上传沿用同一类型限制。
4. 已选素材继续展示在输入框上方，保留图片或视频类型图标、素材名和移除操作；引用标签仍可在提示词内以 `@图片N`、`@视频N` 使用。
5. 切换模型或生成类型时，清理新模型不再支持的参考素材，并提示用户已移除的数量；服务端现有的数量与 MIME 校验仍作为最终保护。

## 异常与边界

- 没有可用模型时，入口禁用并提示原因。
- 模型不支持任何图片/视频引用时，隐藏入口，避免上传无效素材。
- 上传失败、格式不支持、引用超出模型数量限制继续使用现有错误提示与提交拦截。

## 验证

- 单元测试覆盖模型能力到 `accept`/类型筛选的映射及切换模型后的不兼容引用清理。
- 组件测试确认统一入口、素材类型筛选与上传/素材库来源仍可用。
- 执行相关单测、类型检查和生产构建；不运行 E2E。
