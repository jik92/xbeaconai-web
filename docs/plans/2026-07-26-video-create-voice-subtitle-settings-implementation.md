# 一键成片配音与字幕设置实施计划

## 1. 契约与持久化

- 在 `shared/video-create/` 定义四个音色、三档语速、三种风格和六种字幕预设。
- 扩展项目输入、分镜和素材版本 Schema，保存音频设置键与字幕样式 ID。
- 生成新的 Drizzle migration，并保持旧项目通过默认值兼容。

## 2. Provider 与 API

- 恢复 Volc Speech 的两项受管凭据和 Doctor 检测。
- 新增配音操作级可用性，不改变一键成片模块整体门禁。
- 新增项目媒体设置更新、预设试听和批量生成配音接口。
- 批量接口只选择开启配音且缺失音频或配置已过期的分镜，每个分镜独立投递 BullMQ Job。

## 3. Worker 与媒体处理

- 为视频任务增加 `audio-generate` 操作，并在 Job 数据中保存不可变配音设置快照。
- 使用 Volc Speech 的预设音色、语速和风格生成音频，成功后才替换当前音频引用。
- 让分镜生成复用同一配音路径，并记录音频设置键。
- 让字幕合成根据共享预设生成 FFmpeg `force_style`，素材版本记录使用的字幕样式。

## 4. 前端

- 在分镜表头增加配音和字幕设置入口。
- 配音 Dialog 提供四个真实试听卡片、语速、风格、保存与批量生成。
- 字幕 Dialog 提供六种与实际参数一致的预览、保存与重新合成提示。
- 展示音频和字幕样式过期状态；Volc Doctor 不可用时只禁用试听和配音生成。

## 5. 验证

- 覆盖设置默认值、持久化、所有权、冲突、批量筛选、幂等、Volc 请求映射、Doctor、字幕参数和前端结构测试。
- 生成 OpenAPI 与客户端 SDK。
- 使用隔离的 `YAOZUO_DATA_DIR` 运行数据库检查、相关单测、`make ci`、类型检查和生产构建。
- 按仓库约定不运行 E2E。
