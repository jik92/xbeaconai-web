# 一键成片单分镜多镜头 Prompt 设计

## 目标

点击单个分镜的“AI生成视频”后，仍提交当前分镜的独立视频任务，但当前分镜内部自动拆成 2～3 个子镜头。最终提示词严格采用“全局基础设定 + 分镜内容”两部分格式，不输出额外说明。

## 子镜头计划

- 分镜生成阶段由模型同时产出当前分镜内部的结构化子镜头计划。
- 当前分镜不足 10 秒时通常生成 2 个子镜头，10～15 秒时通常生成 3 个子镜头。
- 优先按口播语义和标点拆分；无法自然分句时按字数均衡拆分。
- 每个子镜头包含人物动作、口播、说话神态、音色语气、时长、景别、构图、背景和光线。
- 子镜头时长至少 1 秒，总和必须严格等于当前分镜时长。
- 已有分镜没有结构化计划时，服务端根据现有口播和画面提示词生成确定性兼容计划，不要求用户重新生成分镜。

## 图片引用分类

- `@ImageN` 继续作为 Seedance 的唯一技术引用名。
- 每张图片另有 `人物` 或 `商品` 业务分类。
- 人像库图片默认是人物，项目商品图片默认是商品，手动新增图片默认是商品。
- 弹窗允许切换手动图片的分类。
- Prompt 中使用 `@Image1（人物）`、`@Image2（商品）`；多张商品图片可以共享“商品”分类。
- 视频和音频继续使用 `@VideoN`、`@AudioN`，不使用人物/商品分类。

## Prompt 格式

最终 Prompt 只能包含以下两部分：

1. `### 第一部分：全局基础设定`
   - 约束条件
   - 人物形象
   - 人物神态
   - 镜头视角
   - 背景描述
   - 光线分析
   - 音色设定
   - 画质要求
   - 视频总时长
2. `### 第二部分：分镜内容（按播放顺序逐条输出分镜，每条独立成段，并标注序号）`
   - 分镜序号
   - 人物动作描述
   - 画面口播文案
   - 人物说话神态
   - 音色语气设定
   - 分镜时长
   - 景别
   - 画面构图
   - 背景环境描述
   - 光线风格分析

不再输出“绑定参考素材”“执行要求”“画面生成要求”或模板外说明。参考图片直接嵌入对应的全局设定和分镜字段。

## 数据与接口

- 为分镜记录增加可选的结构化生成计划 JSON，通过新的 Drizzle migration 演进。
- 分镜生成模型输出、Store、API draft 和前端类型同步更新。
- 提交视频任务的外部字段保持现有 prompt、附件和生成设置；结构化计划只用于生成可编辑的最终 prompt。
- 图片附件增加可选分类字段，并在服务端验证图片只能是人物或商品，非图片不得带该分类。

## 验证

- 单元测试覆盖 2/3 子镜头拆分、口播完整性、时长守恒、旧数据兼容和严格模板。
- 单元测试覆盖人像/商品默认分类、多个商品分类、重编号后分类保留和非法分类校验。
- 更新 OpenAPI 与 SDK，运行数据库检查、相关单测、完整单测、类型检查和生产构建。
- 不运行 E2E，除非用户另行明确要求。
