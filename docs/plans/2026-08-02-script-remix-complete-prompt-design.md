# 新版脚本二创完整提示词设计

## 目标

每个分镜只保留一个主要 textarea，展示并编辑该分镜最终用于图片和视频生成的完整提示词，避免用户分别维护口播、画面、动作、运镜和一致性要求。

## 方案

- 在分镜契约中增加可选 `prompt`。新模型结果必须生成完整提示词；旧记录缺少该字段时，由现有结构化字段稳定合成。
- 结构化字段继续保留，用于原文完整性、标题、时长及历史记录兼容，不再在解析结果界面分别提供 textarea。
- 解析结果界面每个分镜保留标题、建议时长和一个“完整提示词” textarea。
- 九宫格、单张参考图和视频生成均优先使用用户编辑后的完整提示词，保证界面展示内容与实际请求一致。

## 验证

- 测试新模型结果的完整提示词解析和旧分镜的回退合成。
- 测试九宫格、单图和视频请求均包含编辑后的完整提示词。
- 静态检查每个分镜编辑区域只包含一个 textarea。
- 运行相关 API/Worker 测试、类型检查和生产构建。
