# 新版脚本二创分镜字段 UI 设计

## 目标

消除分镜卡片中无标签数字和输入框的歧义，同时保持一个完整提示词 textarea。

## 已确认设计

- 卡片顶部显示分镜序号。
- 标题输入框显示可见标签“分镜标题”。
- 时长输入框显示可见标签“建议时长”，框内右侧固定显示单位“秒”，范围保持 1–60。
- 唯一 textarea 显示可见标签“完整提示词”，右侧显示当前字符数与 8000 字上限。
- 不增加解释性副标题，不改变提示词和时长的业务契约。

## 验证

- 静态测试断言上述标签、单位、字符上限存在且分镜编辑区仍只有一个 textarea。
- 运行新版脚本二创相关测试、类型检查和生产构建。
