# 通用 DataTable 表头与内容分割线设计

## 目标

统一所有使用共享 `DataTable` 的页面：表头具有稳定、明确的视觉层级，内容区域不再使用横向分割线。

## 方案

- 表头保持 40px 高度和 sticky 行为。
- 表头使用 `surface-muted` 浅灰背景、12px 中等字重的 `ink` 文字。
- 表头与内容之间保留一条结构性 hairline，帮助识别列标题区域。
- 内容行移除所有横向分割线，仅保留现有的克制悬停背景。
- 空状态、加载状态、错误状态、列宽、行高和滚动逻辑保持不变。
- 所有业务页面通过共享组件自动获得新样式，不增加页面级覆盖。

## 验证

- 更新共享组件测试，断言表头背景、文字语义和唯一结构分割线。
- 断言内容行不包含 border 样式，同时保留 hover 状态。
- 运行相关单元测试、Biome、TypeScript 类型检查、生产构建及差异检查。
