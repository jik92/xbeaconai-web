# 资产导航真实数量设计

## 目标

资产导航中的素材库、人像库、商品库和音色库统一显示真实条目数量，替换目前仅人像库显示写死 `1125` 的不一致状态。

## 数据口径

- 素材库：当前登录用户全部 `media` 类型素材数量，不受当前文件夹筛选影响；
- 人像库：`portraits.json` 中实际可用人像总数；
- 商品库：当前登录用户商品总数；
- 音色库：当前登录用户 `voice` 类型资产总数。

数量为 `0` 时也显示 `0`，避免把“还未加载”和“空库”混为一谈；加载失败时不展示数字，但不影响导航使用。

## 数据流

`AppShell` 使用 TanStack Query 复用项目已有查询键：

- `["asset-library", "media", ""]`
- `["portrait-library"]`
- `["product-library"]`
- `["asset-library", "voice"]`

素材页现有的新增、删除和更新逻辑已经按这些前缀失效缓存，因此导航数量会随缓存刷新同步变化。导航配置只保存静态名称、路径和图标，数字由运行时查询结果按资产 ID 注入，不再维护写死 badge。

## 交互与视觉

沿用现有侧边栏 `<i>` 数字样式，不新增说明文字、颜色或布局。展开状态显示数量，折叠状态保持现有导航行为。菜单编辑模式不显示运行时数量，避免把数字误认为可编辑内容。

## 验证

- 纯函数测试验证四个资产 ID 到数量的映射，包括 `0` 和加载失败；
- AppShell 渲染测试验证四个资产入口均使用运行时数量，不再包含写死 `1125`；
- 运行格式检查、相关单测、类型检查和生产构建。
