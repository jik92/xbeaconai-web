# 爆款二创可选音色与素材错误设计

## 目标

爆款二创的视频分析只要求商品图和分镜视频。口播音色是可选项：未选择、曾选择后删除，均不得阻断视频分析。素材错误必须指出实际失效的素材类型。

## 交互

- 在现有口播音色选择控件标题中标明“选填”，继续复用共享 `DashedPickerTile`。
- 不再从 `localStorage` 自动恢复上次选择的音色，避免已删除素材被隐式带入新项目。
- 已选择音色时提供清除操作，用户可以恢复为不使用音色。
- 若提交前发现当前音色已经从素材库删除，清除失效选择并以无音色请求继续视频分析。
- 若音色列表校验本身失败，不静默丢弃有效选择，保留原错误反馈。

## 服务端校验

- 商品图、分镜视频和可选音色分别查询和校验。
- 商品图或分镜视频不存在时继续返回 `ASSET_NOT_AVAILABLE`，文案明确为“引用的商品或视频素材不存在”。
- 请求显式携带的音色不存在时返回 `VOICE_ASSET_NOT_AVAILABLE`，文案明确为“引用的音色素材不存在或已删除”。
- 音色类型不正确时继续返回 `INVALID_VOICE_ASSET`。

## 测试

- 前端回归测试覆盖音色“选填”、不再持久化选择、可清除选择及提交前过滤已删除音色。
- API 集成测试覆盖失效音色的专用错误，且确认不携带音色时仍能创建分析任务。
- 运行相关测试、TypeScript 类型检查和生产构建；不运行 E2E。
