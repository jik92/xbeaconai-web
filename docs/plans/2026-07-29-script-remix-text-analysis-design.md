# 脚本二创文本解析设计

## 目标

脚本二创不上传或校验分镜视频。用户保留商品、人像、口播音色，并在“脚本填充”中输入完整脚本；AI 自动拆分为可继续校对和生成的视频分镜。

## 方案

1. 在既有 `video-remix` 项目请求中增加 `workflowKind: "video" | "script"` 与 `scriptContent`。视频二创维持现有必填视频校验；脚本二创要求非空脚本，不接收视频素材。
2. 脚本二创根任务保存由服务端生成的 UUID 分镜标识，而不是伪造素材库视频。Worker 使用 Ark 文本模型结合商品、人像、音色和脚本生成每条完整分镜提示词。
3. 前端在脚本模式下隐藏分镜视频上传与预览，改为脚本分镜列表；提示词校对、分镜生成、合并成片复用同一项目工作区。
4. 后续分镜生成接口和 Worker 将脚本分镜识别为合法来源；它们不读取原视频，仅用已校对的提示词及引用商品/人像素材提交生成。

## 保护与校验

- 脚本限制为 20–12,000 个字符；模型输出必须是 1–20 条、每条不少于 20 字的分镜提示词。
- 保持商品、人像、音色的当前所有权校验；脚本模式不会放宽任何素材访问权限。
- 解析失败返回明确的文本解析错误，不会静默回退到视频解析或模拟结果。

## 验证

- 为请求模式与脚本文本分镜解析补充单元测试。
- 执行 API 文档/SDK 生成、类型检查、构建和相关单测。
