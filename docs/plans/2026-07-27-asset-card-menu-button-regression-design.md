# 素材卡片与用户菜单按钮样式回归修复设计

## 背景

原生按钮统一替换为共享 shadcn `Button` 后，素材库、人像库、场景库的可点击卡片和用户下拉菜单行没有显式声明视觉语义，继承了 `Button` 的默认主操作样式。结果是卡片和菜单行出现深色背景、居中布局或错误文字颜色。

## 方案

保留所有交互元素对共享 `Button` 的复用，为不属于主操作的交互容器显式设置 `variant="ghost"`：

- 商品素材卡、人像卡和场景卡继续由业务样式控制卡片布局与边框。
- 音色名称行保持无边框、左对齐和占满可用宽度。
- 用户菜单的个人资料、账号与密码、退出登录行保持无默认背景，并在悬停时使用克制的表面色。
- 不修改真正的主操作、次操作、筛选按钮和业务状态逻辑。

## 验证

- 增加静态回归测试，覆盖三个资产页面和用户菜单中上述 `Button` 的 ghost 语义。
- 运行相关单元测试、TypeScript 类型检查和生产构建。
- 检查最终 diff，确认不包含无关改动。
