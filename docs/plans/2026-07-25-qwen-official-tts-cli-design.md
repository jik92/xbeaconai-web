# Qwen 官方方言 TTS CLI 设计

## 目标

提供一个基于阿里云百炼官方 Qwen-Audio-TTS HTTP API 的 Bun CLI，可通过参数选择模型、音色、方言、配音风格、文本、随机种子和输出路径，并提供一组内置试听样例。

## 设计

- 从用户指定的业务空间 CSV 读取 `apiKey` 和 `workspaceId`，密钥只保留在内存中。
- 使用业务空间专属 `SpeechSynthesizer` 端点和官方嵌套 `input` 请求格式。
- 方言采用官方明确支持的固定目录，不加入实验性城市方言。
- 风格与方言分别转换为自然语言指令，再组合为最终 `instruction`。
- 单条模式生成一个 WAV；`--samples` 模式生成八个固定组合到桌面目录。
- 音频 URL 下载最多重试三次，避免临时 OSS 连接重置导致整批失败。

## 验证

- 单元测试覆盖参数解析、方言与风格校验、指令组合和请求体。
- 静态检查与 TypeScript 类型检查。
- 使用真实官方接口生成八个官方方言样例，并用 FFprobe 验证 WAV、24kHz、单声道和有效时长。
