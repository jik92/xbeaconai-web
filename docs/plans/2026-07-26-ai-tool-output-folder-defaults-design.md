# AI 工具独立默认导出文件夹设计

## 背景

当前公共保存位置组件只出现在少数任务中，并且“设为默认”仍指向账号的全局素材文件夹默认值。AI 工具箱中的其他新建任务没有保存位置，不同任务也无法分别记住自己的常用导出目录。

## 目标

- AI 工具箱中的每一种新建任务都显示公共保存位置组件。
- 每个账号按 AI 工具模块分别保存默认导出文件夹。
- 切换某一任务的默认导出文件夹不影响其他任务。
- 新建文件夹后自动选择，并只设为当前任务的默认导出文件夹。
- 所有任务提交时携带 `outputFolderId`，实际生成物使用该文件夹。
- 设置随账号跨浏览器和设备同步。

## 数据模型

新增 `module_output_folder_defaults` 表：

- `owner_user_id`：账号 ID。
- `module_id`：AI 工具模块 ID。
- `folder_id`：该模块的默认导出文件夹 ID。
- `created_at`、`updated_at`：审计时间。
- `(owner_user_id, module_id)` 唯一，保证每个账号每种任务只有一个默认值。

账号和文件夹删除时通过外键级联清理映射。Store 只允许写入当前账号拥有的文件夹，并且只接受已注册的 AI 工具模块 ID。

## API 与数据流

提供受保护的模块默认文件夹接口：

- 获取某模块的默认文件夹。没有模块设置时返回账号素材库默认文件夹。
- 设置某模块的默认文件夹。服务端校验模块和文件夹归属。

前端公共 `SaveLocationPicker` 接收 `moduleId`。组件加载文件夹和该模块的默认值；当前值为空或失效时选择模块默认值。用户选择文件夹时立即更新当前任务的模块默认值。新建文件夹后创建、选中，并把它写成当前模块默认值，不再修改账号全局默认素材文件夹。

提交任务时统一写入 `outputFolderId`。API 再次验证文件夹属于当前账号；Worker 优先使用任务中的 `outputFolderId`，不再为 AI 工具静默替换成账号全局默认文件夹。

## 前端范围

AI 工具箱当前九个模块全部包含保存位置：

- AI 创作 `ai-generate`
- 视频分割 `video-cut`
- 素材理解 `media-understand`
- 视频混剪 `video-mashup`
- 音色克隆 `voice-clone`
- 视频续写 `video-renewal`
- 字幕擦除 `subtitle-erase`
- 画质增强 `video-enhancement`
- 即梦 `kickart`

通用创建弹窗在字段列表末尾统一渲染保存位置，不再依赖各模块重复声明 `saveLocation` 字段。音色克隆的专用创建弹窗也复用相同组件。独立的视频混剪页面继续使用同一模块 ID。

## 失效与错误处理

- 模块尚未设置时回退账号全局默认素材文件夹，但不会影响其他模块。
- 模块默认文件夹被删除时映射随外键清理，下次自动回退。
- 设置失败时保留当前选择并显示错误；任务提交仍由服务端做最终归属校验。
- 无可用文件夹时禁止提交，但保留新建文件夹能力。

## 验证

- Store 测试覆盖账号隔离、模块隔离、回退和文件夹删除。
- API 测试覆盖鉴权、模块校验、文件夹归属和读写。
- 组件测试覆盖模块默认初始化、选择后仅更新当前模块、新建后设为模块默认。
- 配置测试证明九个 AI 工具模块都获得保存位置。
- Worker/任务提交测试证明 `outputFolderId` 贯穿真实保存路径。
- 运行数据库迁移检查、相关单测、`make ci`、类型检查和生产构建；不运行 E2E。
