# AI Tool Output Folder Defaults Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every AI 工具箱 task a save-location setting whose default folder is persisted independently per account and module.

**Architecture:** A new Drizzle table stores `(ownerUserId, moduleId) → folderId`. Protected API routes expose the resolved default and update it; the shared React picker owns module-specific initialization and updates, while every submitted AI-tool job carries the selected `outputFolderId` through to its Worker.

**Tech Stack:** Bun, React 19, TanStack Query, Hono OpenAPI, Zod, SQLite, Drizzle ORM, Bun Test.

## Global Constraints

- Work directly on `main`; do not create a branch.
- Cover all nine current modules whose `group` is `AI 工具箱`.
- Defaults are account-scoped and module-specific.
- New folders become the current module's default, not the account-wide asset default.
- Keep `web/api/generated/`, `openapi/openapi.json`, and `drizzle/meta/` generated by their project commands.
- Do not run Playwright E2E.
